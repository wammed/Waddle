## 1. 🤖 AI 支援 & コマンド生成

完全ローカルの Ollama を活用したコマンド生成・AI チャット支援です。

| ショートカット | 対象 | 動作内容 |
| :--- | :--- | :--- |
| `Ctrl + K` | 全体 | **AI コマンド自動生成モーダル** を開く |
| `Enter` | AI モーダル | 生成されたコマンドをターミナルに入力（実行前に確認・編集可能） |
| `Ctrl + Enter` | AI モーダル | 生成されたコマンドをターミナルで **即時実行** |
| `Esc` | AI モーダル | モーダルを閉じる |

> 💡 **安全設計**: 危険なコマンド（`rm -rf /` 等）が生成された場合、Rust の `CommandPolicy` エンジンにより警告バッジが表示され、ワンクリックでの誤実行を防ぎます。

## 2. 🪟 ターミナル & マルチペイン操作

Waddle は 1〜4 画面のマルチペイン分割（全10プリセット）に対応しています。

| ショートカット | 対象 | 動作内容 |
| :--- | :--- | :--- |
| `Ctrl + T` | 全体 | 新規ターミナルタブを開く |
| `Ctrl + W` | 全体 | 現在のターミナルタブを閉じる |
| `Ctrl + Shift + W` | 分割ペイン | 現在アクティブな **ペインのみを閉じる** |
| `Ctrl + Shift + S` | 分割ペイン | ペインの配置を **スワップ（入れ替え）** |
| `Alt + 1` | 全体 | **単一ペイン（1画面）** に切り替え |
| `Alt + 2` | 全体 | **左右 2 分割** レイアウトに切り替え |
| `Alt + 3` | 全体 | **左メイン 3 分割** レイアウトに切り替え |
| `Alt + 4` | 全体 | **2×2 格子グリッド** レイアウトに切り替え |
| `Alt + Z` | 分割ペイン | アクティブペインを **最大化（ズーム） / 元に戻す** |
| `Alt + ↑ / ↓ / ← / →` | 分割ペイン | キーボードでペイン間のフォーカスを移動 |
| `Ctrl + Alt + 矢印` | 分割ペイン | キーボードで境界線をリサイズ（5% 刻み） |

## 3. 📋 コピー & ペースト (クリップボード同期)

ターミナル、内蔵エディタ、ホスト OS（Firefox, VS Code 等）間でシームレスに同期します。

| ショートカット | 対象 | 動作内容 |
| :--- | :--- | :--- |
| `Ctrl + C`（テキスト選択時） | ターミナル | **選択範囲をクリップボードにコピー** |
| `Ctrl + C`（未選択時） | ターミナル | 通常の **SIGINT (`^C`)** を送信（実行中プロセスの中断） |
| `Ctrl + Shift + C` | ターミナル | 選択テキストを確実にコピー |
| `Ctrl + V` / `Ctrl + Shift + V` | ターミナル | クリップボードからターミナルへ貼り付け |
| `Ctrl + Shift + A` | ターミナル | ターミナル画面内のテキストを全選択 |

## 4. 📝 簡易内蔵エディタ (`Ctrl + E`)

設定ファイル（dotfiles, YAML, TOML, JSON, env等）やスクリプトを安全かつ超軽量に編集できます。

| ショートカット | 対象 | 動作内容 |
| :--- | :--- | :--- |
| `Ctrl + E` | 全体 | **内蔵エディタ** の表示/非表示を切り替え |
| `Ctrl + S` | エディタ内 | ファイルを保存（UID検証 & アトミック保存） |
| `Ctrl + A` | エディタ内 | 全テキストを選択 |
| `Ctrl + C` / `X` / `V` | エディタ内 | コピー / 切り取り / 貼り付け |
| `Ctrl + Z` | エディタ内 | 元に戻す（Undo） |
| `Ctrl + Y` / `Ctrl + Shift + Z` | エディタ内 | やり直し（Redo） |
| `Ctrl + F` | エディタ内 | **完全一致 検索バー**（ReDoS 安全設計）を開く |
| `Ctrl + H` | エディタ内 | **置換バー** を開く |
| `Ctrl + Shift + K` | エディタ内 | **AI コードリファクタリング** を呼び出し |
| `Tab` / `Shift + Tab` | エディタ内 | ソフトタブ（4 スペース）インデント / アンインデント |

## 5. 🔍 検索 & セッション履歴

| ショートカット | 対象 | 動作内容 |
| :--- | :--- | :--- |
| `Ctrl + Shift + F` | ターミナル | **ターミナルログ検索バー** の開閉 |
| `Enter` / `Shift + Enter` | 検索バー内 | 次の一致 / 前の一致へ移動 |
| `Ctrl + Shift + H` | 全体 | **セッション タイムライン & 履歴復元** モーダルを開く |
| `Ctrl + Shift + P` | 全体 | **ビジュアル パイプライン ビルダー** を開く |
| `Ctrl + B` | 全体 | **ファイルツリー サイドバー** の開閉 |

## 6. 🐙 Git & システム設定

| ショートカット / 操作 | 対象 | 動作内容 |
| :--- | :--- | :--- |
| `Git バッジ クリック` | ステータスバー | **Git クイックポップオーバー** を開く |
| `Ctrl + Enter` | Git コミット入力 | ステージされた変更をコミット |
| `Ctrl + ,` | 全体 | **設定画面**（テーマ、AI、壁紙、フォント、言語等）を開く |
| `Esc` | 全体 | 開いているモーダル・検索バー・ポップアップを閉じる |
